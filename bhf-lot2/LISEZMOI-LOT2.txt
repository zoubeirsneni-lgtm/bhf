BEBBA — LOT 2 : catalogue public + suivi public (plugin v0.2.0)
Code écrit par Super Z (pas d'OpenCode). Suivez les 5 étapes dans l'ordre.

ÉTAPE 1 — Copier le plugin corrigé dans WordPress
  1. Extraire ce zip.
  2. Copier le dossier "bebba-healthy-food" dans :
     C:\wamp64\www\bebbabhf\wp-content\plugins\
     -> Choisir "Remplacer les fichiers dans la destination".

ÉTAPE 2 — Copier le même dossier dans le dépôt de travail
  3. Copier le dossier "bebba-healthy-food" dans :
     C:\Users\DELL PRO\Desktop\Zia\bhf\
     -> "Remplacer les fichiers dans la destination".
  4. Copier aussi :
     - docs\demo_seed_lot2.sql      -> C:\Users\DELL PRO\Desktop\Zia\bhf\docs\
     - docs\demo_cleanup_lot2.sql   -> C:\Users\DELL PRO\Desktop\Zia\bhf\docs\
     - REPORT_LOT_2.md              -> C:\Users\DELL PRO\Desktop\Zia\bhf\

ÉTAPE 3 — Charger les données de démonstration
  5. Icône WAMP -> phpMyAdmin (root, mot de passe vide).
  6. Clic sur la base "bebba_bhf" (colonne de gauche).
  7. Onglet "Importer" -> choisir demo_seed_lot2.sql -> "Exécuter".
     (Le message "X lignes insérées" est le succès attendu.)

ÉTAPE 4 — Réactiver le plugin
  8. WordPress -> Extensions -> désactiver "Bebba Healthy Food" puis l'activer.

ÉTAPE 5 — Tester (collez ces adresses dans le navigateur)
  http://localhost/bebbabhf/wp-json/bebba/v1/health
     -> doit afficher "version":"0.2.0"
  http://localhost/bebbabhf/wp-json/bebba/v1/categories
     -> 2 catégories (Bowls équilibrés, Jus détox)
  http://localhost/bebbabhf/wp-json/bebba/v1/products
     -> 2 produits avec baseIngredients et customization
  http://localhost/bebbabhf/wp-json/bebba/v1/products/prod-chicken-bowl
     -> détail du Poulet Bowl
  http://localhost/bebbabhf/wp-json/bebba/v1/supplements
     -> 2 suppléments

Puis envoyer sur GitHub (invite de commandes, une seule ligne) :
  cd "C:\Users\DELL PRO\Desktop\Zia\bhf" && git add -A && git commit -m "feat(lot-2): catalogue public + suivi public (categories, products, supplements, tracking, seed demo)" && git push origin wordpress-migration
